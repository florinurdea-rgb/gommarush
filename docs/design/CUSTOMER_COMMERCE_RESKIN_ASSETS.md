# Customer commerce reskin assets

These assets are the approved icon source for the customer-facing reskin.

## Rules
- Keep the existing GommaRush logo exactly as-is. Do not redraw, replace, recolour, or regenerate it.
- Use only the exported icons in `CommerceIcons.tsx` for the commerce reskin where these concepts appear.
- Do not substitute emoji, icon-library glyphs, generated SVGs, stock icons, tyre photos, or brand logos.
- Icons inherit `currentColor`; visual colour is controlled by the existing design tokens/classes.
- This asset commit does not authorize copy changes or backend/business-logic changes.
